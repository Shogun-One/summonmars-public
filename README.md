# Summon Mars public website

Public marketing pages and their explicitly referenced music, video, and image assets only.

The private `Shogun-One/summonmars` repository owns the mobile apps, playable game implementations, backend code, release records, signing material, and build tooling. Do not copy its root or history here.

Verbia and Ocean of Aliens pages here are promotional only. GitHub Pages publishes this repository’s `main` branch root at summonmars.com.

Public promotional URLs: https://summonmars.com/verbia and https://summonmars.com/oceanofaliens. Ocean of Aliens is the public game name; do not use the old Asteroid Drift title in promotional artwork. Legacy HTML URLs redirect to these pages.
